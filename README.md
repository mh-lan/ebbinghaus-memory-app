# 艾宾浩斯记忆卡片 (Ebbinghaus Memory App)

一个极简、优雅的本地优先 (Local-first) 记忆复习应用。采用现代浅色毛玻璃 (Glassmorphism) UI 风格设计，核心基于**艾宾浩斯遗忘曲线**算法，帮助您科学、高效地复习知识点。

## ✨ 核心特性

- **科学记忆算法**：内置艾宾浩斯遗忘曲线调度算法，自动计算下一次最佳复习时间。
- **流畅手势交互**：
  - 👆 **上滑 (或键盘 ↑)**：记住了，触发绚丽的消散粒子特效。
  - 👇 **下滑 (或键盘 ↓)**：没记住，卡片直接划走，重新进入复习队列。
  - **点击卡片 (或键盘 Space)**：翻转查看背面的答案。
- **多源数据同步**：
  - **🌐 网络端同步**：支持绑定任意 Raw URL（如 Gitee / GitHub），只要有网，启动应用时即会在后台静默抓取并合并更新！
  - **📁 本地文件导入**：直接选择电脑上的 Markdown 文件进行读取。自动将文件名转化为“知识标签”。
- **Markdown 完美渲染**：支持加粗、列表、代码块等多种排版格式，让您的笔记不再单调。
- **标签精准过滤**：复习时可自由组合要测试的“来源标签”，指哪打哪。
- **PWA 离线支持**：免费部署至 Gitee Pages 或任意静态托管服务后，手机端“添加到主屏幕”即可变成无需联网、全屏运行的独立原生 App！

## 🚀 如何运行

本项目是一个基于 Vite + React + TypeScript 构建的纯前端单页面应用 (SPA)，数据完全存储于您的浏览器本地 `IndexedDB`，没有后端，极致安全。

### 本地开发运行
1. 确保您的电脑已安装 [Node.js](https://nodejs.org/)。
2. 在终端中进入项目目录，安装依赖：
   ```bash
   npm install
   ```
3. 启动开发服务器：
   ```bash
   npm run dev
   ```
4. 浏览器打开 `http://localhost:5173` 即可体验。

### 编译与打包
```bash
npm run build
```
执行完毕后，项目根目录会生成一个 `dist` 文件夹。您可以将该文件夹中的所有文件上传至任意静态网页托管平台（如 GitHub Pages, Gitee Pages, Vercel, Netlify）。

## 📦 数据格式规范

本应用原生支持 Markdown 格式作为题库，解析规则极简：
- 以 `#`、`##` 等开头的标题将作为卡片的**正面 (Front)**（即问题）。
- 标题下方直到下一个标题出现之前的所有正文内容，将作为卡片的**背面 (Back)**（即答案，支持 Markdown 渲染）。

示例：
```markdown
# 什么是马太效应？

凡有的，还要加给他，叫他有余；没有的，连他所有的也要夺过来。（强者愈强，弱者愈弱）。

## 黄金圈法则的核心是什么？

不要一上来就说做什么（What），要反向沟通：
1. **Why（为什么）**：我们为什么要干这件事？（愿景、价值）
2. **How（怎么做）**：我们的核心策略和原则是什么？
3. **What（做什么）**：具体你需要做哪几件事？
```
